# Glossary

- **Unit:** config-bearing attrset with optional claims, children, identity, and merge profile.
- **Claim:** ownership restriction on one or more axes.
- **Axis:** one ownership dimension implementing the registered axis contract.
- **Descriptor:** one axis's author syntax, scope, context, and roster metadata.
- **Top/global:** the identity claim. For set axes, `exclude []`.
- **Narrow/meet:** combine parent and child claims without widening.
- **Leaf:** composed config-bearing node with an effective claim.
- **Stage:** registered validation over a leaf, full tree, or survivor set.
- **Relation:** registered compatibility rule between two axes.
- **Roster:** canonical members, aliases, membership, dimensions, and display data.
- **Context:** concrete entities for one resolve.
- **Inactive:** valid leaf rejected by selection.
- **Impossible:** declaration that can't match modeled members or relations.
- **Conflict:** selected co-owners provide incompatible scalar values.
- **Contributor:** selected leaf identity plus opaque effective owners carried into merge.
- **Provenance:** path-aligned contributor tree from tracked merge.
- **Lock:** opt-in path authorization over contributors.
- **Merge profile:** named list strategy, scalar policy, and attrset treatment.
- **Trace:** one-context explanation generated by the real pipeline.
- **Matrix:** read-only projection across modeled fleet contexts.
- **Canonical host ID:** `"<system>/<name>"`.
- **Bare alias:** human host name resolved to a canonical ID when unique.
